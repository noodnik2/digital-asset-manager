# Design State — Digital Asset Manager

_Maintained by Designpowers orchestrator. Updated after every agent handoff._

---

## Brief Summary

**Problem:** Power users with large digital asset collections are underserved by generic filesystem tools. Manual lists, folder structures, and one-off scripts create compounding overhead and leave collection value unrealized.

**Primary Persona:** Tech-savvy owner-operator. Large existing MIDI collection. Runs the app locally. High workflow expectations. Values coherence and efficiency over polish.

**Core Loop:** Select → Operate → Inspect → Operate again (recursive). The Working Set model makes this the default path.

**Primary Success Metric:** The user can chain a full select → transform → inspect → export cycle without writing a script or leaving the application.

**Brief:** `docs/designpowers/briefs/2026-05-17-digital-asset-manager-discovery.md`
